# Контрольные вопросы

**1. Укажите возможные способы подключения к сетевому оборудованию.**  
К сетевому оборудованию можно подключаться следующими способами:  
– через консольный кабель (локальное подключение для первичной настройки);  
– через Telnet (удалённый доступ по сети);  
– через SSH (удалённый защищённый доступ по сети);  
– через веб-интерфейс (если поддерживается устройством).  

**2. Каким типом сетевого кабеля следует подключать оконечное оборудование пользователя к маршрутизатору и почему?**  
Для подключения ПК к маршрутизатору используется прямой витопарный кабель (Copper Straight-Through), так как соединяются устройства разных типов: оконечное устройство и сетевое оборудование.  

**3. Каким типом сетевого кабеля следует подключать оконечное оборудование пользователя к коммутатору и почему?**  
Для подключения ПК к коммутатору также используется прямой витопарный кабель (Copper Straight-Through), поскольку соединяются разные типы устройств: хост и коммутатор.  

**4. Каким типом сетевого кабеля следует подключать коммутатор к коммутатору и почему?**  
Для соединения коммутатора с коммутатором применяется перекрёстный кабель (Copper Cross-Over), так как соединяются однотипные устройства.  

**5. Укажите возможные способы настройки доступа к сетевому оборудованию по паролю.**  
Доступ по паролю может быть настроен:  
– для консольной линии (line console 0);  
– для удалённых подключений по линиям VTY (line vty 0 4);  
– с использованием привилегированного режима (enable secret);  
– через создание локальных пользователей (username и password/secret).  

**6. Укажите возможные способы настройки удалённого доступа к сетевому оборудованию. Какой из способов предпочтительнее и почему?**  
Удалённый доступ можно настроить с помощью протоколов Telnet и SSH. Предпочтительным является SSH, так как он обеспечивает шифрование передаваемых данных и более высокий уровень безопасности по сравнению с Telnet, который передаёт информацию в открытом виде.
