# Контрольные вопросы

**1. В чём состоит основной принцип работы NAT (что даёт наличие NAT в сети организации)?**  
NAT (Network Address Translation) — это технология преобразования IP-адресов, позволяющая заменять внутренние (частные) адреса сети на внешний (публичный) адрес при выходе в Интернет.  
Использование NAT позволяет:  
– экономить публичные IP-адреса;  
– скрывать внутреннюю структуру сети (повышение безопасности);  
– обеспечивать доступ локальной сети к внешним ресурсам через один или несколько публичных адресов.  

**2. В чём состоит принцип настройки NAT (на каком оборудовании и что нужно настроить для из локальной сети во внешнюю сеть через NAT)?**  
NAT настраивается на пограничном маршрутизаторе, соединяющем локальную и внешнюю сеть.  
Для настройки необходимо:  
– определить внутренние (inside) и внешние (outside) интерфейсы;  
– создать пул внешних IP-адресов (или указать один адрес);  
– настроить список доступа (ACL), определяющий, какие внутренние адреса будут транслироваться;  
– применить правило NAT (например, с перегрузкой — overload).  

**3. Можно ли применить Cisco IOS NAT к субинтерфейсам?**  
Да, NAT можно применять к субинтерфейсам.  
Субинтерфейсы могут быть помечены как **ip nat inside** или **ip nat outside**, что позволяет использовать NAT в сетях с VLAN и маршрутизацией через один физический интерфейс (router-on-a-stick).  

**4. Что такое пулы IP NAT?**  
Пул NAT — это диапазон публичных IP-адресов, используемых для динамической трансляции внутренних адресов.  
При выходе в Интернет внутренним узлам временно назначается один из адресов из пула. Это позволяет обслуживать множество клиентов с использованием ограниченного числа внешних IP-адресов.  

**5. Что такое статические преобразования NAT?**  
Статический NAT — это постоянное соответствие между внутренним и внешним IP-адресом (или портом).  
Используется для публикации серверов во внешнюю сеть.  
Например, внешний адрес и порт могут быть жёстко привязаны к внутреннему серверу, что позволяет получать доступ к сервисам (HTTP, FTP, SMTP и др.) из Интернета.
